## Task 2: Simple Math with Variables ⭐

**Description**: Use variables and `print()` to perform simple calculations.

**Requirements**:
- Create two variables: `num1` and `num2` with any whole numbers
- Create a third variable: `sum_result` that adds them together
- Print all three values

**Example**:
```python
num1 = 10
num2 = 20
sum_result = num1 + num2
print(num1)
print(num2)
print(sum_result)
```

**Expected Output**:
```
10
20
30
```

**Challenge**: Can you print them on ONE line instead of three lines? (Hint: Use commas!)

## Task 6: Data Type Explorer ⭐⭐⭐

**Description**: Create variables of different data types and check/print their types.

**Requirements**:
- Create 4 variables: one string, one integer, one float, one boolean
- Print the value of each
- Print the type of each

**Example**:
```python
name = "Zainab"
age = 20
height = 5.6
is_student = True

print(name)
print(age)
print(height)
print(is_student)

print(type(name))
print(type(age))
print(type(height))
print(type(is_student))
```

**Expected Output**:
```
Zainab
20
5.6
True
<class 'str'>
<class 'int'>
<class 'float'>
<class 'bool'>
```
