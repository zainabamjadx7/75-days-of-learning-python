## 📚 Learning Path

### Weeks 1-2: Python Basics
- Variables & data types
- Operators & expressions
- Input/output
- String manipulation

### Weeks 3-4: Control Flow
- If/else statements
- Loops (for, while)
- Break & continue

### Weeks 5-7: Functions & Data Structures
- Functions & parameters
- Lists, tuples, dictionaries
- List comprehensions

### Weeks 8-10: File Handling & Modules
- File I/O operations
- Working with libraries
- Introduction to APIs

### Weeks 11-12: Object-Oriented Programming
- Classes & objects
- Inheritance
- Polymorphism

### Weeks 13+: Real-World Projects
- Data analysis with pandas
- Database operations
- Data visualization
- Web scraping basics

## 🚀 How to Use This Repository

### For Self-Learning
1. **Read the notes** (`day-XX-notes.md`) - Learn the concept
2. **Attempt the tasks** (`day-XX-tasks.md`) - Solve without looking at solution
3. **Compare solutions** (`day-XX-solution.py`) - See my approach
4. **Experiment** - Modify code, break things, learn from failures!

### For Running Code
```bash
# Clone the repository
git clone https://github.com/zainabamjadx7/75-days-of-learning-python.git
cd 75-days-of-learning-python

# Navigate to a specific day
cd days/day-01

# Run the solution
python day-01-solution.py
```

### For Interactive Learning
```bash
# Run Python interpreter
python3

# Copy code from solution and test line by line
# Or use Jupyter Notebook (optional)
jupyter notebook
```

## 🤝 How to Contribute

We welcome **all skill levels** to contribute! Here are some ways:

### 1. Solve Unsolved Tasks
- Browse the `/days` folder
- Find tasks without solutions
- Create a pull request with your solution

### 2. Improve Explanations
- Found something confusing? Clarify it!
- Add more examples to the notes
- Explain complex concepts better

### 3. Add Alternative Solutions
- Different approach to a problem?
- Create `day-XX-solution-alternative.py`
- Explain why your method is good

### 4. Report Issues
- Found a bug in the code?
- Typo in the documentation?
- Open an issue with details

### Getting Started with PRs

```bash
# 1. Fork the repository (GitHub button)
# 2. Clone your fork
git clone https://github.com/YOUR-USERNAME/75-days-of-learning-python.git

# 3. Create a new branch
git checkout -b add-day-5-solution

# 4. Make your changes
# 5. Commit with clear message
git commit -m "Add solution for Day 5 with explanation"

# 6. Push to your fork
git push origin add-day-5-solution

# 7. Open a Pull Request on GitHub
# (GitHub will guide you through this)
```

**See [CONTRIBUTING.md](CONTRIBUTING.md) for detailed guidelines.**
